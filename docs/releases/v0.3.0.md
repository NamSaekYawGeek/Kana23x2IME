# 23×2 Kana v0.3.0 · iOS

本次发布更新 iOS 键盘扩展：保留双 23 键假名布局及 Z / X / C 操作，调整键帽、候选栏和触摸交互，提供可交给 SideStore 签名的未签名 IPA。

iOS 版本号为 **0.3.0**，构建号为 **4**。

此版本只发布 iOS 产物。Android 仍使用 v0.2.0，不将旧 APK 标记成 v0.3.0。

## 下载与安装

- `Kana23x2-v0.3.0-ios-unsigned.ipa`：iOS 15 及以上的未签名真机包，包含宿主 App、键盘扩展和完整离线词典。
- `Kana23x2-v0.3.0-ios-simulator.zip`：供 Mac 上 iOS 模拟器安装的 App，不适用于 SideStore。
- `Kana23x2-v0.3.0-light.png`、`Kana23x2-v0.3.0-dark.png`、`Kana23x2-v0.3.0-landscape.png`、`Kana23x2-v0.3.0-feedback-settings.png`：本次构建的浅色、深色、横屏和反馈设置模拟器截图。
- `SHA256SUMS.txt`：上述产物及构建记录的 SHA-256 校验值。
- `BUILD-INFO.json`：版本号、构建号、源提交和通过测试的 GitHub Actions 运行记录。

在 iPhone 上将 IPA 导入 SideStore；如提示选择扩展，请保留 **KanaKeyboard**。SideStore 必须同时为宿主 App 和键盘扩展签名。此安装路线不需要本地 Mac 或 Xcode，但需要已配置可用的 SideStore。

安装后，前往 **设置 → 通用 → 键盘 → 键盘 → 添加新键盘 → 23×2 Kana**，再在输入框中通过 🌐 切换。常规离线输入无需开启“允许完全访问”。

## 键盘与交互

- 调整为接近系统键盘的圆角键帽、阴影和按压高亮，使用系统符号绘制 Shift、删除和切换等操作键。
- 适配浅色、深色输入框和横屏布局；字符按压预览保持在键盘区域内。
- 删除键点按删除一次，长按连续删除；候选刷新和文字变化不会重建正在按住的删除键。
- 没有待确定文字时，长按空格并左右拖动可移动光标。
- 候选支持横向浏览和展开；收起候选后回到当前假名板。
- 继续支持平片假名切换、浊音、半浊音、小假名、长音、数字、符号和表情，以及离线假名转汉字。

## 可选声音与触感

没有待确定文字时，点击候选栏的齿轮可分别开关按键声音和轻触震动。两个开关初始为开启，并在键盘扩展内保存；实际声音和触感需要在系统设置中为 23×2 Kana 开启“允许完全访问”。不开启此权限仍可正常离线输入，并保留按压高亮和字符预览。

声音使用 iOS 公开的输入点击接口，遵守系统键盘点击音和静音设置。触感使用独立的轻触反馈开关，不读取或同步苹果系统键盘的“触感”开关，也不保证与系统键盘的震动波形完全相同。未增加联网功能或 App Groups 数据共享。

普通键每次按下反馈一次，长按删除随实际重复删除反馈，松手不再额外触发。候选确定、假名板／平片切换和进入光标移动模式也提供相应提示。

## 验证与范围

发布流程先通过 Python 词典与 IPA 打包测试、Swift 核心测试、模拟器和未签名真机编译，再在 iPhone 模拟器中启用实际安装的键盘扩展，验证假名输入、两板切换、平片切换、`にほん → 日本` 候选确定、连续删除和深色／横屏显示。交互检查还覆盖拖出按键取消输入、反馈开关保存与恢复、在系统设置中开启“允许完全访问”、扩展读取权限状态及开启反馈后的输入路径；这些检查不验证实际声音或震动输出。只有检查通过，才上传同次构建的产物并发布；发布前再次校验版本号、完整词典和远端文件的 SHA-256。

模拟器测试不等同于 iPhone 真机验收。SideStore 签名、安装、系统键盘启用、声音、触感，以及不同 App 内的交互仍需在设备上验证；模拟器截图不能证明设备上声音或震动正常。

待确定文字保留在键盘内，点击假名行或候选词后才提交。移动光标、切换输入框或隐藏键盘会取消未确定文字。密码、部分电话号码输入框及禁止第三方键盘的 App 会使用系统键盘。
