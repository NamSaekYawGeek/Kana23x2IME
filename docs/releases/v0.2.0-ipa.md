# 23×2 Kana v0.2.0

首次同时提供 Android 和 iOS 构建，保留双 23 键假名布局及 Z / X / C 操作；README 已完整改为中文。

## 下载与安装

- `Kana23x2-v0.2.0-android-debug.apk`：Android 8.0 及以上的可安装测试版，使用调试签名。安装后在系统设置中启用并选择 23×2 Kana。
- `Kana23x2-v0.2.0-ios-simulator.zip`：iOS 模拟器 App，内含键盘扩展。
- `Kana23x2-v0.2.0-ios-device-unsigned.zip`：iOS 15 及以上的未签名真机 `.app`，供自行打包或签名使用。
- **[`Kana23x2-v0.2.0-ios-unsigned.ipa`](https://github.com/NamSaekYawGeek/Kana23x2IME/releases/download/v0.2.0/Kana23x2-v0.2.0-ios-unsigned.ipa)**：新增的未签名 IPA，包含主 App 和 `KanaKeyboard` 键盘扩展，可导入 SideStore 签名安装，无需本地 Mac/Xcode。
- `SHA256SUMS.txt`：原有 APK 和 ZIP 文件的 SHA-256 校验值。
- `Kana23x2-v0.2.0-ios-unsigned.ipa.sha256`：新增 IPA 的 SHA-256 校验值。

Android 调试签名由构建环境生成，不保证与以前下载的测试包一致。若系统提示签名不兼容，需要先备份必要数据再卸载旧包；卸载会清除该键盘的本地学习和剪贴板历史。

### SideStore 安装 IPA

在 SideStore 的 My Apps 中点「＋」导入 IPA，并保留 `KanaKeyboard` 扩展。安装后打开一次主 App，再到「设置 → 通用 → 键盘 → 键盘 → 添加新键盘」中启用「23×2 Kana」，无需开启完全访问。若安装后列表未出现该键盘，可尝试为扩展单独注册 App ID 后重装；此排查方法尚未完成真机验证。

此版本使用自带的 SKK 衍生词典和转换引擎，不接用苹果系统日语输入法的词库或候选栏。已有安装后键盘未出现在设置列表的反馈，原因仍待排查。

新增 IPA 来自 [GitHub Actions 构建 44345033276](https://github.com/NamSaekYawGeek/Kana23x2IME/actions/runs/44345033276)，提交 `33f9d469ac2357bea3bdf85e7f1c49b40c4f0a2b`；iOS 源码与 v0.2.0 标签一致，本次增加 IPA 打包与校验。云端测试、模拟器/真机编译及 IPA 结构校验通过，真机交互仍待验收。

## iOS 新增

- 真正的系统键盘扩展、启用说明和测试输入框。
- 双假名板、平片假名切换、浊音/半浊音、小假名、长音、数字、符号及表情。
- 离线 SKK 汉字候选、前缀预测及基础词尾/文节转换；词典采用内存映射查找。
- 无需“允许完全访问”。待转换文字显示在键盘内，确认后提交；移动光标、切换输入框或隐藏键盘会取消尚未确认的文字。

## Android 修复

- 兼容 Android 打包时自动解压并改名的词典资源，修复安装包内词典无法载入的问题，并新增 APK 词典检查。
- 删除最后一个组合假名后，正确清除输入框中的文字。
- 删除 Emoji 和扩展汉字时不再拆坏 UTF-16 代理对，并正确处理选区。
- 移动光标后不再复用旧组合；重建输入视图时保留活动组合。
- 长音 `ー` 留在当前词中，分解形式的浊音和半浊音不再被错误清除。
- 密码字段和禁止个性化学习的字段不再记录候选；修复敏感剪贴板标记和清空历史行为。
- 修正 AndroidX 测试依赖配置；共用词典解析不再泄露 SKK 词尾限制块的分隔符。

## 验证与范围

发布构建通过 Python 词典测试、Swift 核心测试、Android 回归测试，以及 Android APK、iOS 模拟器和未签名真机编译。

这是供体验和验证的键盘原型，尚未完成真机交互验收。iOS 首版尚无个人学习、最近词或剪贴板历史；Android 对复杂多码点 Emoji 尚不保证整组删除。长句及歧义转换能力仍有限。
