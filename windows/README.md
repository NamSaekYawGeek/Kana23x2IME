# Kana23x2 Windows 桌面预览版

Windows 版把 23×2 布局的按键转换成微软日语输入法可以接收的罗马字按键。词典、汉字转换、候选框和选词均由 **Microsoft IME** 提供，程序不附带移动端词典。

这是 **0.3.3 桌面预览版**。核心布局与编码逻辑已有自动化测试；**微软日语 IME 的实际候选交互仍需 Windows 实机验收**。编译成功不能证明所有目标应用均兼容。

## 运行

1. 使用 Windows 10 / 11 x64，安装日语语言和 **Microsoft IME**。
2. 解压整个 `Kana23x2-win-x64.zip`，双击其中的 `Kana23x2.exe`。请保留同目录的依赖文件。自包含包不要求另装 .NET SDK 或运行时。
3. 在目标应用的输入框中切换到日语 Microsoft IME，开启假名输入（任务栏显示「あ」），并在微软 IME 设置中使用**罗马字输入**。
4. 按 Kana23x2 布局输入。每次按键立即发送给微软 IME，假名直接出现在目标输入框的组合文本中。
5. 按空格开始转换；需要时再按空格展开系统候选列表。方向键、数字候选键和 Enter 继续按微软 IME 的规则操作。

程序启动时启用映射，在前台日语 IME 已开启且使用全角平假名或片假名时捕获布局按键。罗马字输入是微软 IME 的键盘设置。可暂停 Kana23x2，在平假名模式下依次按 K、A，显示「か」即可确认设置正确。无法确认 IME 状态时按键原样放行。焦点或模式切换后会立即排队检查并定期复查；检测完成前快速按下的键可能仍按原键位输入。请根据“布局与试输”窗口的状态提示检查设置。

关闭说明窗口只会隐藏到系统托盘；右键托盘图标可打开说明、暂停或退出。**Ctrl + Alt + K** 随时暂停／启用映射。

不需要管理员权限。当前版本不支持向以管理员身份运行的目标窗口发送输入，也不请求提权绕过这一限制。

## 输入方式

布局映射即时送入微软 IME，组合文本和候选框由系统维护：

```text
Kana23x2 布局按键 → 罗马字按键 → 目标输入框中的微软 IME 组合文本 → 系统候选框
```

空格、Enter、Esc、Backspace 和候选导航始终使用微软 IME／目标应用的行为。

| 按键 | 行为 |
| --- | --- |
| Q W E R T Y U I O P | 第一板：あ い う え お か き く け こ；第二板：な に ぬ ね の は ひ ふ へ ほ |
| A S D F G H J K L | 第一板：さ し す せ そ た ち つ て；第二板：ま み む め も ら り る れ |
| V B N M | 第一板：と や ゆ よ；第二板：ろ わ を ん |
| Z | 仅切换第一板／第二板，保留当前平片假名模式和输入焦点。板号可在托盘提示或试输窗口查看 |
| X | 对最近由本程序输入的一个假名切换浊音，属于实验性后缀变形 |
| C | 第一板切换小假名；第二板切换半浊音，属于实验性后缀变形 |
| 单独 CapsLock | 在映射生效的日语模式下立即切换系统全角平／片假名；在其他模式下保留系统行为 |
| 单独轻按 Shift | 松开按键后，只把最后一个键对应的假名换成另一板的基础假名；再次轻按可换回。前面的文字、当前板号和平片状态不变 |
| `-` | 长音 `ー` |
| Backspace | 原样交给微软 IME／目标应用，同时将当前编辑片段的短暂记录回退一位；连续编辑时可继续用 X／C／Shift 修改前一假名 |
| Esc | 原样交给微软 IME／目标应用，并清除当前编辑片段记录 |
| 空格、Enter、方向键 | 原样交给微软 IME，进行转换、选词、确认或导航 |
| 数字、逗号、句号 | 原样放行，包括系统候选选择 |
| Ctrl + Alt + K | 暂停／启用映射 |

按住 Shift 的组合及 Ctrl／Alt／Win 快捷键保留系统行为。切换焦点不会从本程序重放旧读音；已经进入目标应用的组合文本由微软 IME 按自身规则处理。

微软 IME 决定原生候选框的排序。开启输入学习后，常选的片假名词可能提前。微软没有公开供按键映射程序统一提高片假名词权重的接口。要直接确认读音的全角片假名写法，可在组合文本中按 F7，再按 Enter，例如把 `かめら` 确认为 `カメラ`。[微软日语 IME 快捷键与学习设置](https://support.microsoft.com/en-us/windows/hardware/input-devices/microsoft-japanese-ime)

### X／C／Shift 尾字变形与删除

托盘中的 **“尾字变形（X/C/Shift，实验性）”默认开启**，可在不兼容的应用中关闭。变形通过发送 **Backspace + 替换假名的罗马字按键** 实现。

单独 Shift 修改的是最后一个实际输入键的板位。例如在第二板输入 `まま` 后，轻按 Shift 得到 `まさ`，再次轻按回到 `まま`。Z 仍只切换后续输入的板号。Shift 使用另一板的基础假名，因此 `は → X → ば → Shift → か → Shift → は`，不会把浊点带到另一板。

程序为同一输入位置连续输入／编辑的片段保留最多 **256 个假名字素**的短暂记录。最近一次有效输入或编辑后 **3 秒**内，Backspace 删除会按顺序回退记录，露出前一个可供 X／C／Shift 修改的假名。例如输入 `はか`，删除 `か` 后，X 可把剩下的 `は` 改成 `ば`。超过容量的更早记录不会因删除而重新出现。

空格、Enter、Esc、其他系统按键、快捷键、鼠标操作、焦点或系统平片模式改变都会清除整个片段记录；超过 3 秒未继续编辑也会清除。Z 保留记录，以便换板后使用 C。记录清除后，X／C／Shift 不再尝试修改之前的文字。按住 Shift 的组合键保留系统行为，不触发尾字换板。

**这些记录不能证明目标应用仍处于未确认组合状态。** 全局映射程序无法可靠读取所有应用的 IME 组合状态；目标应用或 IME 如果自行确认了文字，退格仍可能作用于已确认文本，或者一次删除范围与本地记录不同。请先在试输框、记事本等应用的临时文本上验证；在自动确认或自定义编辑控件中出现异常时，关闭实验性变形。当前版本不能承诺跨应用的尾字变形不会误删文字。

## 兼容范围

- 当前目标为微软日语 IME 的默认快捷键配置和罗马字输入模式。日语“假名键盘输入”模式、其他厂商 IME 不在本版支持范围内。
- 普通按键、Z 换板及尾字替换沿用微软 IME 当前的平片假名模式。单独 CapsLock 立即发送日语 IME 的 `IME On`（平假名）或 `Shift + IME On`（全角片假名）模式操作，具体行为取决于当前 IME 对这些按键的支持。
- 支持两板基础假名、常用浊音／半浊音、小假名和长音的罗马字编码。不能可靠编码为微软罗马字按键的任意附浊点组合、`ゕ／ゖ` 和扩展小片假名等不会应用变形，不会改用 Unicode 直接插入来绕过 IME。数字和标点由系统处理。
- 新旧微软 IME、不同 Windows 版本及宿主应用可能暴露不同的状态信息。状态查询失败时程序不捕获布局按键；不要据此断言已支持所有应用。
- 使用真实键盘事件发送读音，不读写剪贴板，不直接设置目标文本，不安装独立的系统输入法。应用仍受 Windows 输入权限和目标窗口行为限制。
- 不将输入内容写入文件；尾字编辑只在内存中保留当前片段最多 256 个假名字素的短暂记录。该记录不是微软 IME 的组合状态副本。

## 构建与自动化测试

准备 **.NET 10 SDK**，从仓库根目录执行：

```powershell
dotnet run --project windows/Kana23x2.Core.Tests -c Release
dotnet run --project windows/Kana23x2.Desktop.Tests -c Release
dotnet publish windows/Kana23x2.Desktop -c Release -r win-x64 --self-contained true -o windows/dist/Kana23x2-win-x64
Copy-Item windows/README.md windows/dist/Kana23x2-win-x64/README.md
Compress-Archive -Path windows/dist/Kana23x2-win-x64 -DestinationPath windows/dist/Kana23x2-win-x64.zip -Force
```

核心项目针对 `net10.0`，可在 Linux、macOS 和 Windows 测试；桌面项目针对 `net10.0-windows`。跨平台编译可以检查 Windows 桌面代码及打包，但不能代替 Windows 实际运行。

**Actions → Build Windows → Run workflow** 会测试核心逻辑，在 Windows 上使用模拟 IME 验证桌面按键处理，并检查实际窗口和原生钩子能否启动／退出。构建产物 `Kana23x2-Windows-x64` 内含自包含 ZIP。真实微软日语 IME 的选词和跨应用编辑仍需实机验证。

## Windows 实机验收

以下交互仍需在安装了日语 Microsoft IME 的 Windows 机器上完成，建议先测默认新版 IME、记事本和程序内试输框，再测常用浏览器或编辑器。

| 检查 | 预期 |
| --- | --- |
| 分别从系统平假名和全角片假名模式依次按 Q、Z、Q、Z、Q | 得到 `あなあ` 或 `アナア`，焦点始终留在原输入框，板号回到第一板，系统维持原假名模式 |
| 两板全部 46 个键位、Z 往返 | 每次按键立即在目标输入框显示正确假名；已有读音不变 |
| `は → ば → は`、`は → ぱ → は`、`ぱ → ば` | 实验性 X／C 在当前应用的未确认组合中正确替换，检查有无删除过多、重复或提前确认 |
| 小假名、长音、`コーヒー` | 读音正确送入微软 IME，长音保留在同一转换中 |
| 全角日语模式下单独 CapsLock | 按键立即切换系统平片模式，不用再输入一个假名；板号不变 |
| 第二板输入 `まま`，单独 Shift 两次 | `まま → まさ → まま`，只替换尾字，当前板号和系统平片模式不变 |
| `は → X → ば → Shift → か → Shift → は` | 尾字换板采用基础假名，不携带原变形 |
| Shift + 字母／方向键及 Ctrl／Alt／Win 组合 | 保留系统行为，不触发尾字换板，不遗留修饰键 |
| `んあ`、`んや`、`んん` | 罗马字 `nn` 的衔接不吞字、不重复；确认实际微软 IME 结果 |
| 平片混合读音 | 模式切换不会改写先前片段或提前确认组合；不同宿主应用单独检查 |
| 空格、再次空格、方向键、数字、Enter、Esc | 系统候选正常展开、导航、选中及取消 |
| 组合文本时 Enter、随后再次 Enter | 使用微软 IME／目标应用原有确认和换行行为 |
| 输入 `はか`，Backspace 后按 X；再删除到更早假名并用 C／Shift | 删除按顺序回退当前记录，前一假名仍可编辑；不恢复已清除或超过容量的旧记录 |
| 空格、Enter、Esc、点击、切换窗口、Tab、快捷键、CapsLock 后再按 X／C／Shift | 旧的编辑片段已清除，不会再退格修改旧假名 |
| 输入后等待超过 3 秒再按 X／C／Shift；Z 换板后立即按 C | 超时不变形；换板保留最近目标并按第二板规则处理 C |
| 目标应用自动确认或自动改写文字 | 检查 X／C／Shift 是否误改已确认文字；该场景不能仅凭缓存证明安全 |
| 切换英文／日语、IME 关闭或状态不可读 | 不满足输入条件时不拦截布局按键 |
| Ctrl + Alt + K、托盘退出、长按键 | 可暂停与退出；按下／释放配对，不遗留修饰键 |
| 管理员目标窗口、输入发送失败 | 不误报输入完成，不自动重复可能已部分送达的内容 |
